# Assets de marca

Coloca aqui el logo de Win para el header del correo:

- Archivo: `win_logo.png`
- Version recomendada: logo **WIN en blanco + claim "EL INTERNET DE LOS WINNERS"**,
  en PNG con **fondo transparente** (es la version que se ve bien sobre el header naranja).
- Recortado sin margen transparente (440x227 px); se muestra a 110x57 px en el header,
  asi que queda nitido en retina. Si lo cambias, ajusta `width`/`height` del `<img>`.

Si el archivo no existe, el correo usa un wordmark de texto "win" como respaldo.
